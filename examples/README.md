# Example comics

Small sample comics for trying ComicHero, all original artwork made for this project by Fotoh Mbaku.

| File | Layout | Chapters |
| --- | --- | --- |
| `ember-knight.zip` | manifest | 87 |
| `hollow-crown.zip` | manifest | 203 |
| `iron-bloom.zip` | manifest | 52 |
| `neon-ronin.zip` | manifest | 64 |
| `skyforge-academy.zip` | manifest | 118 |
| `the-last-archivist.zip` | manifest | 142 |
| `tidebound.zip` | manifest | 31 |
| `Paper Moon Café.cbz` | plain folders (`cover/`, `Chapter/<n>/`) | 2 |

To keep the files small, each manifest comic has three page images that every chapter reuses; a manifest may list
the same file in more than one chapter. Open any zip to see the layout ComicHero expects.

```
python3 server.py examples
```
